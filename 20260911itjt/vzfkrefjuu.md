# 一双“圣手”铸传奇——沈靖南忆老师黄承达

> 更新时间：2026-09-11 (UTC+8)

**专题合集**

#教师节#中山一院

**杏林济世三春暖，师道润物细无声。在中山一院115载峥嵘岁月里，一代代名师以仁心为灯、以医术为炬，照亮医学之路，更点亮无数后辈的医学理想。在教师节与建院115周年之际，我们特别推出“致敬名师・薪火相传”系列专题，以文为舟、以字为桨，回望名师名家睿智深邃的育人之道，追忆那些沉淀在光阴里的谆谆教诲，再现中山医跨越世纪、薪火相传的师道精神。**

黄承达，1929年11月出生，广西人，上海第一医学院副博士研究生毕业。曾任中山医科大学附属第一医院骨科主任，教授，硕、博士导师。中华医学会骨科学分会副主任委员，第二、三届全国骨肿瘤学组组长，广东省医学会骨科学分会主任委员，卫生部创伤骨科学专题委员会委员。黄承达教授长期从事骨科医、教、研工作。1955年研究外科止血海绵成功，填补了国内空白。1962年，成功研制出同源无机骨和人造骨并应用于临床，属世界首创。1964年，成功实施世界第一例断肢再植手术。

**讲述人：****沈靖南，中山一院骨肿瘤科学科带头人，二级**教授、主任医师、博士生导师。

20世纪80年代的每周四下午，中山一院骨科办公室里，病理科刘子君教授、放射科肖官惠教授、骨外科黄承达教授齐聚一堂。三位代表科室最强力量的专家，带着各自团队和学生，共同针对每一位骨肿瘤患者的病情展开热烈讨论。

会上智慧云集，观点碰撞之间，三大科室将疑难骨肿瘤患者的病情抽丝剥茧，仔细剖析，并形成缜密的诊断和治疗方案。

作为年轻的医学生，沈靖南一边认真旁听，一边在笔记本上奋笔疾书，他对老师们的巧思妙想如获至宝。

病理科刘子君教授（左一）、骨外科黄承达教授（左三）等专家开展骨肿瘤“三结合”讨论

如今回头看，沈靖南不禁感慨，这三科联合讨论病例的情景，不就是当今推崇的MDT模式（多学科会诊）吗？据他所知，早在50多**年****前，中山一院骨科就有了MDT模式了。**他坦言，能沉浸在这样的学术氛围里，对于当时还是研究生的自己而言，非常幸运。

40年过去，青丝已变银发，但沈靖南回忆当年师从黄承达教授的点滴，仍充满崇敬和怀念。

**“绣花工”创奇迹**

**世界首例断腿再植成功**

改革开放初期，沈靖南完成了医学生本科的学业，踏入医院岗位。这位年轻医生最初经历了外科轮转，对骨外科产生了独特情结。

1985年，他通过了研究生考试，来到了广州的中山医学院，成为黄承达教授的研究生。当时，黄承达教授已是我国骨科、显微外科及骨肿瘤学科的开拓者及著名教授，在医、教、研方面都有高深的造诣：**他1957年研制外科止血海绵成功，填补国内空白；1962年研制人造骨，并应用于临床。1964年施行世界首例断腿再植手术成功**，受到中南第一书记陶铸的接见及嘉奖。到了上世纪70年代，黄承达教授又在国内率先开展了恶性骨肿瘤切除和人工假体置换的保肢手术，在80年代开展了椎体肿瘤切除和人工椎体置换等国内先进的手术。

1964年11月23日，成功实施世界第一例断腿再植手术

“老师的载誉很多，他常常提醒我们，**做医生要不断往前看，要以解除患者痛苦为初心**。”老师的寄语，与沈靖南选择骨外科的初衷不谋而合。师生两人时常的交流，无形中加深了师徒缘分。

沈靖南在跟随黄承达教授学习期间，亲身体会到断指再植、断腿再植手术的难度，以及对医者的考验。当年没有外科显微镜，做手术要靠放大镜来放大血管，术者要具备“绣花工”的精细技术，还要讲究耐性。

1960年代，黄承达（右一）与中山一院骨科主任邝公道教授（左二）在手术中

“老师带教手术，除了要我们观摩技术手法，还要我们树立为患者设想，尽力保住肢体的治疗理念。正因如此，有伤者特地从香港或澳门来医院，找黄教授抢救。**做断肢接驳手术需要分秒必争，黄教授无论寒冬酷暑都随传随到**，手术往往持续十几个小时，可他为了伤者避免致残，从无怨言。”

**一双妙手屡开先河**

**自创修复材料惠及患者**

80年代黄承达教授的工作重心有了转变。随着中山一院联合病理科、影像科和中山大学肿瘤医院放疗、化疗科，建立了骨肿瘤研究中心(中山医科大学骨肿瘤中心)，黄承达教授开始研究骨肿瘤诊断和治疗。

面对骨肿瘤较大的专业难度，黄承达教授总是锲而不舍地从理论到临床广泛研究，逐步完善骨肿瘤的病因、病理、化疗治疗和手术治疗。比如，那深深印在沈靖南记忆里的“三科结合会诊”，便是黄承达教授一手促成的。

“‘三结合’会诊会，不是一次两次举办的。黄教授将这一模式坚持了十几年，每周定期举行，成为骨外科和其他多学科协同作战的惯例。”**正是这种三科结合讨论，让骨与软组织肿瘤的诊断规范及金标准逐步形成**。

也得益于这一模式，“中山医骨肿瘤科”的名声正式打响，业界有了“**北有积水潭，南有中山医**”之说。沈靖南也紧跟黄承达教授的脚步，深耕骨肿瘤救治领域。

在手术方面，黄承达教授也屡屡创新。“老师的一双巧手，不仅能缝合微细血管，还能发明器械。他不断有新发明造福患者。除了以前研制的止血海绵、人造骨，在骨肿瘤科成立后，他还为胫骨上段肿瘤切除患者设计了人造关节。”

制作骨水泥假体，修复骨肿瘤后的骨缺损

沈靖南回忆，在骨外科修复材料普遍缺乏、进口困难的年代，修复材料该如何生产，既没有先例，也没有参考。要为患者修复切除肿瘤后的骨骼组织，就要靠自己亲手设计。

在当时简陋的条件下，黄承达教授反复研究和设计出了人造关节。他甚至亲自去工厂监督制作，材料是当时最好的不锈钢材料。

不久后，他又专为骨肿瘤活检设计了一款啮齿状的穿刺针。该器械的精妙之处，就在于针头上有个倒刺，插进病灶后一夹，就能取到肿瘤硬组织，改良了传统的抽吸针头难以取材的缺陷。 

1989年，黄承达教授设计了一种新的齿咬型骨肿瘤穿刺活检针

这些成就不仅仅属于黄承达教授，更属于整个中心团队。能和黄承达教授一起共事，沈靖南觉得作为后辈非常荣幸。“黄教授所做并非创新这么简单，他也在潜移默化影响着我们，**让我们能在忙碌的诊疗中‘停下来’思考，思考我们作为医生，还可以为患者多做些什么。**”

**出国交流被多次挽留**

**外国同行赞誉他为“圣手”**

在沈靖南追随黄承达教授学习、工作的时光里，**中山一院骨外科、骨肿瘤科的无数病人，从愁眉苦脸，到眼里有光**。

“有位印尼华侨，因患胫骨骨巨细胞瘤，在当地、新加坡和香港等大医院多次手术，仍反复复发，最后被告知只能截肢。患者近乎绝望地找到黄教授，经他手术及精心治疗，最终保存了肢体，回国后恢复了工作。每年春节，他总寄来贺卡，把教授比作再生父母。”

不止印尼患者，沈靖南印象深刻的、经黄承达教授手术医治的病人，还有切除肩部恶性肿瘤后保肢成功且康复后继续举行个人演奏会的钢琴家，有成功分离的连体婴，有跟腱断裂手术后重夺世界冠军的羽毛球运动员，有肩部损伤恢复后打破世界纪录的举重选手。

1989年，他在美国加州、伊利诺州等地访问并作显微外科手术示范，得到外国同行好评，**当地伊利诺斯州州报及电视台大幅报道，赞誉他为“圣手”**。他还多次出国，在国外取得突出业绩，多次被挽留长期工作。

1989年8月30日晚，美国伊利诺斯州电视台专题报道黄承达教授做手术示范

但每次结束完国外的研究和访问，黄承达教授仍如期回国，一如既往回到中山医的讲坛，回到诊室，给沈靖南等学生教学。

每次回国，他总会带回一些特别“手信”——那就是几大箱高质量的科研成果和资料。“他将资料交给学校、交给我们整理。他家中数千册书、学术专著、杂志资料，就是他的财富。”

1989年8月31日，美国伊利诺斯州日报在首版刊载黄承达教授手术示范

**为后人留下专著**

**离世前仍关心学生论文**

黄承达教授作为师长，积攒了一辈子的治疗经验，他经常想到的是如何培养年轻人，使骨外科和骨肿瘤的学科发扬光大，学术后继有人。为此，他参与编写医学百科全书、骨科手术学、矫形外科学、外科学等专业书和教科书。

除了医疗工作外，他还参与了大量科研教学工作，发表论文几十篇。先后取得全国科技大会奖，卫生部和广东省科技进步奖等多项奖励。

黄承达教授参加广东省科学技术奖励大会

“对于科研工作，他同样一丝不苟，每组数据都反复核算，所写的文章反复修改。**他手上还有几大箱卡片资料，记载了几十年科研工作的毕生心血。**他对年轻医生、研究生及学生循循教导，耐心讲解，倾囊相授。在评审学术论文时严谨细致，逐字逐句反复推敲，对引用的文献亲自查阅核对，不厌其烦。”在黄承达教授培养的学生中，除了沈靖南，还有郭卫、李建民等三位教授已成为中国骨肿瘤领域的接班人。

黄承达教授（前排右二）与学生们在一起

如今，沈靖南已经是独当一面的学科带头人，带着老师的理想，他在骨肿瘤外科领域建树良多，**他的“绝技”——半盆骨假体重建术，更获评“广东名医绝技称号”**。但沈靖南心里仍留着难以弥补的遗憾：1994年，黄承达教授不幸患病。“他躺在病床上仍关心我和另一位博士的科研论文进展情况。然而，论文答辩前，他就与世长辞了。”

沈靖南深切缅怀恩师高尚的医风、精湛的技术和对医学忘我的奉献精神，“如今，我依然战斗在骨与软组织肿瘤诊治临床一线，**甘愿秉持初心，为之奋斗终生**。”
