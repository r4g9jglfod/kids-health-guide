12月的清晨，天蒙蒙亮，凌冽的寒风还在呼呼作响，小学一年级班主任王老师手机就响个不停，仔细一看，都是学生家长发来的请假信息，内容却惊人的相同：王老师：我家孩子发烧、打喷嚏，咳嗽，需要请假去医院看病。王老师带着对学生的担忧进到学校以后了解到，这样的情况，几乎每个班都是，原来，很多学生得“流感”了。

//

而医院里，都是来看病的家长们，聚在一起谈论：“对呀，我孩子也是高热不退，浑身酸痛，以往感冒发热1、2天就好了，这次4天了还没好，马上就要考试了，可怎么办呀，我这两天照顾她，自己感觉也鼻塞流涕了呢”。

面对来势汹汹的“流感”病人，医院也是认识到防止及治疗“流感”的重要性和紧迫感，除了加大医生坐诊率，尽量减少排队等待时间，同时还积极宣传“流感”知识，希望让更多人认识到“流感”的严重性。

//
**下面就让我们一起学习下有关“流感“的知识吧**
//

流行性感冒：俗称“流感”，是由流感病毒引起的急性呼吸道传染病。可分为甲（A）、乙（B）、丙（C）三型，甲型病毒经常发生抗原变异，传染性大，传播迅速，极易发生大范围流行。甲型H1N1也就是甲型一种。临床上有急起高热、乏力、全身肌肉酸痛、眼结膜炎明显和轻度呼吸道感染症状，主要的表现和普通感冒相仿，但是全身中毒症状比较重。

但不是谈“流感”色变，流感具有自限性，但在婴幼儿、老年人和存在心肺基础疾病的患者容易并发肺炎等严重并发症而导致死亡。

如果有以下症状还是早早来医院就诊更为安全：重症流感病人症状：高热3天不退，神志改变（包括嗜睡，病毒性脑炎症状，惊厥），严重呕吐、腹泻、电解质紊乱，重症肺炎（呼吸频率加快、血痰、脓痰），原有的病情加重。危重流感病人症状：多脏器功能衰竭，坏死性脑病，败血症，休克等危及生命

。

看了流感的严重性，是不是觉得内心瑟瑟发抖，那怎么确诊”流感“呢？

通常，医生会针对每个病患病情，做出血常规检查、生化检查、病原学检查、血清免疫学检查、X线拍片等检查。病毒的抗原和核酸检测可以用于早期诊断。

**如果真的中招，被确诊“流感”怎么办？**

及早应用抗流感病毒药物，在发病36小时或48小时内尽早开始抗流感病毒药物治疗。常用药物有神经氨酸酶抑制剂如奥司他韦、M2离子通道阻滞剂如金刚烷胺和金刚乙胺等。目前各大医院抗流感药储备还是充足的，没有出现“药荒”的现象。

**为什么流感，学生群体多见呢？**

冬春季寒冷，学生在外面活动减少，多集中在教室内，这更增加了传染机会，为了御寒，习惯把门窗关的很严，室内外的空气很难交换，空气相对静止的室内，带有病毒、病菌的飞沫在空气中漂浮，学生在教室时间长，空气不新鲜，自然容易感染呼吸道疾病。另外，寒冷的空气会使鼻粘膜的血管收缩，降低呼吸道的抵抗力，这也是容易得病的原因之一。所以为什么这次学校、幼儿园会大规模出现集体生病请假的原因，就是“流感”搞得“鬼”。

预防的方法

（1）注意保持良好的个人及环境卫生。

（2）勤洗手，使用肥皂或洗手液并用流动水洗手，不用污浊的毛巾擦手。

（3）双手接触呼吸道分泌物后（如打喷嚏后）应立即洗手。喷嚏或咳嗽时应用手帕或纸巾掩住口鼻。

（4）流感患者在家或外出时应戴上口罩，以免传染他人。

（5）增强个人抵抗力：均衡饮食、适量运动、充足休息，避免过度疲劳。

（6）保持室内空气流通。尽量不到人多拥挤、空气污浊的场所。

（7)在流感流行季节前可接种流感疫苗。
